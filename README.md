# AutoChoice — GitLab-версия без шаблонного приложения

Перенесено **только приложение из `machinka-master/autochoice.zip`**. Аксолотль, React-страницы шаблона и посторонний ML-пакет исключены. Docker/GitLab CI оставлены как инфраструктура деплоя.

## Структура

- `index.html` — исходная страница AutoChoice.
- `src/` — JavaScript и CSS AutoChoice, готовый браузерный 3D-бандл и исходник 3D-движка.
- `public/` — изображения, модели GLB, сведения об атрибуции и материалы дуэлей.
- `backend/autochoice/` — отдельный Python-алгоритм фильтрации и рекомендаций.
- `backend/tests/` — Python-тесты.
- `scripts/` — статическая сборка и сервер без сторонних Node-зависимостей.
- `.gitlab-ci.yml`, `Dockerfile`, `deploy/docker-compose.yml` — инфраструктура шаблона, адаптированная под AutoChoice.

## Локальный запуск

Требуется Node.js 20+ (рекомендуется 22).

```bash
npm ci
npm run build
npm run serve
```

Откройте `http://localhost:3000`. Для изменений сайта редактируйте `src/`, затем повторяйте `npm run build`. Собранная папка `dist/` создаётся автоматически.

Python-тесты при наличии pytest:

```bash
PYTHONPATH=backend python -m pytest backend/tests -q
```

## Развёртывание в GitLab

Поместите **содержимое архива в корень репозитория** `machinka`, заменив демонстрационные файлы, а не вложенную папку. В `.gitlab-ci.yml` требуется указать `DEPLOY_HOST` и настроить секреты в Spirit. Pipeline использует `Dockerfile`, публикует образ и разворачивает его на ВМ по `deploy/docker-compose.yml`.

> Деплой в GitLab и сборка Docker здесь не выполнялись.

## Ограничения

Исходный сайт работает как статический frontend и вычисляет рекомендации в JavaScript. Python-модуль — отдельный прототип, **не API**. Каталог в исходном AutoChoice содержит 15 демонстрационных автомобилей. Данные пользователей и результаты дуэлей не сохраняются в PostgreSQL.

В `public/developer/` лежат дополнительные данные и офлайн-дуэли из исходного ZIP. Вложенный дублирующий ZIP удалён, но исходные файлы разработчика сохранены.
